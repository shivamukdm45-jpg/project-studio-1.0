## Project Description
The Student Attendance Management System is a simple project designed to manage student attendance records digitally.

It calculates attendance percentage, displays student records and identifies students having attendance below 75%.

## Technologies Used
- HTML
- CSS
- JavaScript
- Microsoft Excel / LibreOffice Calc
- Microsoft Word / LibreOffice Writer
- PowerPoint / LibreOffice Impress

## Main Features
1. Add student attendance records.
2. Calculate attendance percentage automatically.
3. Calculate present and absent days.
4. Identify students with attendance below 75%.
5. Delete individual student records.
6. Clear all attendance records.
7. Store records using browser LocalStorage.
8. Display attendance summary.

## How to Run the Project
1. Open the 04_Website folder.
2. Double-click on index.html.
3. The website will open in a web browser.
4. Enter student details and attendance days.
5. Click Add Attendance to view the records.
